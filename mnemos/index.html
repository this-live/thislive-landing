Mnemos

Mnemos: memory that stays on your own hardware

Mnemos gives all my AI tools one shared memory. It lives on my own hardware and is filed by project, so the tools remember past work without handing it to someone else's cloud.

What it does

Filed by project

Each project has its own memory. One client's work never shows up in another's.

Works across tools

Claude, Codex, Cursor and local models all read and write the same memory.

Protected shared space

Nothing gets into shared memory by accident. It has to be promoted on purpose.

Deletes you can audit

Removed memories are hidden from every tool but kept as a record, so nothing disappears silently.

Where it stands

In the works. I use it every day, and I'll open source it once it works the way I intend.

What it means for you

When your AI needs to remember your business, that memory should live with you. This is how I set that up.
