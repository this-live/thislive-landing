Maestro

Maestro: the right model for each job

Maestro decides which AI model handles each task. Simple work goes to fast, cheap or local models. The expensive ones only run when the job needs them.

What it does

Local first

It tries models on my own hardware before reaching for a paid one.

Automatic fallback

If one provider hits a limit or goes down, the work moves to the next one instead of stopping.

Secrets stay home

A scan strips keys and secrets out before anything goes to a cloud provider.

A record of each choice

Every routing decision is logged with its cost, so you can check why a model was picked.

Where it stands

In the works. I use it every day, and I'll open source it once it works the way I intend.

What it means for you

This is how hybrid setups keep bills down: routine work stays local and only the hard calls go to a frontier model.
