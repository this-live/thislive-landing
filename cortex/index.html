Cortex

Cortex: the setup I run my own work on

Cortex is the set of tools I run my own business on. It runs on my own machines, and each piece does one job. It's also where I test what I recommend to clients before I recommend it.

What it does

Shared rules

Every tool follows the same definitions for a task, a result and a receipt, so the pieces fit together without drifting.

An honest status screen

One dashboard shows which machines and services are actually running. If something hasn't been checked, it says so instead of showing green.

Runs on my hardware

A GPU machine serves models, a NAS holds memory, and my laptops and desktops run the agents. Nothing is rented that doesn't have to be.

The pieces

Each one stands on its own. Together they're the setup I run every day. Ostium, my newer tool, now covers much of what Surfaces started.

Maestro

Maestro decides which AI model handles each task.

Mnemos

Mnemos gives all my AI tools one shared memory.

Agent Fabric

Agent Fabric splits a big job into pieces and runs several AI workers on it at the same time.

Forge

Forge builds specialist AI helpers for each part of a business: engineering, marketing, sales, finance, operations and more.

Surfaces

Surfaces is how I talk to the system: a voice assistant, a daily planner, a terminal and a desktop app, all on one backend I run.

Where it stands

Part of my own setup. I'm not selling it as a product today.

What it means for you

When I set up a local or hybrid system for you, it follows the same rules: clear records of what ran, honest status, and nothing that only works on my machine.
