# AEO Audit — this.live

**Date:** 2026-08-13 · **Author:** Atlas (for Bryce) · **Status:** draft, findings for approval — no site changes made

Prompted by the Tony Giordano / Hannah Hammond clip (IG reel DaLXIeCyNkZ): consumers increasingly ask ChatGPT/Claude/Gemini instead of Googling. The goal shifts from *ranking on Google* to *being the answer the AI gives*. This audit checks this.live against that bar.

## Executive summary

this.live is well positioned on message ("sovereign, fully-local agentic AI" is a distinctive, quotable position) but thin on the mechanics that make LLMs cite you: structured Q&A content, third-party validation, and machine-readable entity signals. The blog's weekly cadence is an asset — it just isn't packaged for answer engines.

## What answer engines reward (the framework applied)

1. **Clear entity definition** — can an LLM state who/what this.live is in one sentence, from sources it trusts?
2. **Structured, quotable content** — FAQs, comparison pages, "best X for Y" pages, definitional posts that lift cleanly into an answer.
3. **Third-party validation** — reviews, Reddit/HN/forum mentions, directories, podcasts. LLMs weigh what *others* say over what your own site claims.
4. **Consistency of footprint** — same name/positioning across GitHub, LinkedIn, X, Product Hunt, etc.

## Findings

### Strengths
- **Distinct positioning.** "Owned, not rented" / "one-person company on a local fleet" is a category-of-one claim — easy for an LLM to repeat if it encounters it.
- **Named, consistent product entities.** Cortex, Mnemos, Maestro, Agent Fabric, Surfaces, Forge — stable names with dedicated pages. Good entity substrate.
- **Blog cadence + receipts culture.** Weekly posts with concrete specifics (111k+ memories, 8-state lifecycle) are exactly the kind of factual anchors LLMs latch onto.
- **GitHub presence (brycemurad0)** with real repos — LLMs ingest GitHub heavily.

### Gaps (ordered by leverage)
1. **No FAQ / structured Q&A pages.** Nothing on the site is shaped as question → concise answer. This is the single highest-leverage AEO artifact. Candidate questions: "What is a local-first agentic OS?", "Cortex vs LangChain/CrewAI?", "How do I run agents without cloud APIs?", "What is Mnemos memory?"
2. **No comparison / alternative pages.** "Cortex vs. [X]" and "alternatives to [rented agent platform]" queries are where AI assistants get asked for recommendations — and we have no canonical answer for them to quote.
3. **Thin third-party surface.** Little presence in the places LLMs treat as independent validation: Reddit (r/LocalLLaMA, r/selfhosted), HN comments, directories (AlternativeTo, relevant awesome-lists), guest podcast appearances. Bryce's LinkedIn rebuild (in progress) partially covers this.
4. **No structured data / llms.txt.** No evidence of JSON-LD (Organization, Product, FAQPage) or an `/llms.txt` summarizing the site for crawlers. Cheap to add, directly machine-facing.
5. **Blog archive contains pre-March 2026 posts** (Jan/Feb dates visible: 2026-01-12 through 2026-02-23). This contradicts the ratified archive rule (archive starts at public launch, early March; Jan–Feb is backstory, never byline dates). Flagged for the blog-archive-rewrite workstream — an AEO crawler reading those dates gets a founding timeline we no longer tell.
6. **Product pages describe pillars, not problems-in-the-reader's-words.** "Kills provider lock-in" is our framing; the AEO version answers the searcher's phrasing: "how to stop paying per-token for agents", "self-hosted alternative to [X]".

## Recommended actions (phased)

**Phase 1 — on-site, this week (low cost, high leverage)**
- Add `/faq` with 10–15 Q&As, marked up with FAQPage JSON-LD.
- Add Organization + Product JSON-LD to the homepage and each pillar page.
- Publish `/llms.txt` (curated map: what this.live is, pillar one-liners, canonical links).
- Write two comparison posts: "Cortex vs. cloud agent frameworks" and "Self-hosted agent memory: Mnemos vs. hosted memory APIs."

**Phase 2 — footprint, 2–4 weeks**
- 3–5 genuine Reddit/HN contributions per week in relevant threads (build-in-public specifics, not promotion).
- Submit to AlternativeTo and 2–3 awesome-lists (awesome-local-llm, awesome-agents categories).
- Align LinkedIn (per the separate audit) so the founder entity reinforces the company entity — LLMs resolve "Bryce Murad" ↔ "this.live" ↔ "Cortex".

**Phase 3 — measurement, ongoing**
- Monthly AEO probe: ask ChatGPT/Claude/Gemini/Perplexity a fixed panel of 10 questions ("best local-first agent platform", "what is Mnemos memory", …) and log whether/ how this.live is cited. Track movement like rankings. (Good cron job candidate — I can run this fleet-side.)
